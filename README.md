# TDIG_20252

Repositório com os projetos práticos desenvolvidos na disciplina de Tópicos de Desenvolvimento de Interfaces Gráficas (TDIG), do curso de Ciência da Computação. Reúne exercícios progressivos de front-end, partindo de HTML/CSS puro até um projeto com React e hooks customizados.

## 📋 Projetos

### 1. Página de homenagem a Alan Turing
Página estática em HTML/CSS que apresenta uma cronologia da vida e contribuições de Alan Turing para a ciência da computação, incluindo imagem, legenda e linha do tempo com eventos históricos.

📁 `Página de homenagem a Alan Turing/`

### 2. Formulário de pesquisa
Formulário de pesquisa de satisfação em HTML/CSS, com diferentes tipos de campo (texto, e-mail, número, dropdown, radio buttons, checkboxes e textarea) e validação nativa via atributos HTML (`required`, `min`, `max`).

📁 `Formulário de pesquisa/`

### 3. Portfólio pessoal
Estrutura inicial de uma página de portfólio pessoal em HTML/CSS, com navegação, seção de apresentação e área para exibição de projetos.

📁 `Portfólio pessoal/`

### 4. Geo Locator (React + Custom Hook)
Aplicação em React que utiliza a Geolocation API do navegador por meio de um *custom hook* (`useGeolocation`), exibindo latitude, longitude e hemisfério do usuário em tempo real.

📁 `Projeto 4 (React)/reac_custom_hook/React-Custom-Hook-main/`

**Tecnologias:** React 19, React Scripts

**Como executar:**
```bash
cd "Projeto 4 (React)/reac_custom_hook/React-Custom-Hook-main"
npm install
npm start
```

## 🛠️ Tecnologias utilizadas

- HTML5 e CSS3
- React (Hooks, Custom Hooks, Geolocation API)
- Node.js / npm
